# deviceFile测试用例说明

## S001-初始化测试
- 输入数据：initCase
- 前置条件：无
- 测试步骤：

    1.从initCase读入一条新数据；  
    2.构造deviceFile的桩对象；  
    3.逐一比较桩对象属性与读入数据；  
    4.统计不一致个数并输出；  
    5.若测试集读完，则结束测试，并输出测试结果；否则跳到1。

- 预期输出：

    ...  
    case x:true true true true  
    ...  
    case x:true true true fasle  
    ...   
    ALL:x passed y fatal

## S002-频率表测试
- 输入数据：freqTableCase  
- 前置条件：对象已初始化
- 测试步骤：

    1.调用readFreqTable读样例表；
    2.单独读样例表；
    3.对比两侧读取结果并输出判断

- 预期输出： 

    case: 1 2 3 4  
    readFreqTable: 1 2 3 4  
    compare: T T T T
